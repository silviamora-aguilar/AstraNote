AstraNotes Course Artifact Guide

Silvia's SDLC document map

This page groups the project documents by software development life cycle phase so you can review the updated single-user MVP baseline in a clear reading sequence.

Recommended reading flow: Vision -> Requirements -> Design -> Planning -> Verification -> Acceptance

How to use this page

Each phase below answers a different SDLC question. Open only the documents needed for that phase instead of scanning the full workspace every time.

1. VisionWhy are we building AstraNotes?
2. RequirementsWhat must the system do?
3. DesignHow should the solution work?
4. PlanningWhat will we do next and when?
5. VerificationHow will we test and measure done?
6. AcceptanceHow do we close and sign off?

What is covered so far

Single-user local MVP planning baseline is synchronized across requirements, user stories, backlog, traceability, tests, sprint plans, release gates, and customer acceptance.

  • Decision lock complete: FastAPI, Jinja2 + HTMX, SQLite, encrypted note storage, and private note unlock controls.
  • Post-MVP deferrals are explicitly tagged with [Post-MVP] in requirements for out-of-scope clarity (including deferred SMR items, multi-user web foundations, deep nested lists, image paste, and NFR-01 through NFR-05 load targets).
